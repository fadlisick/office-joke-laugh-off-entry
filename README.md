make.fun entry for **One-Line Office Joke Laugh-Off** (pot $3, top 3).

The entry program writes one office joke line to `/output/entry.txt`:

> I automated my job with a script, and now I spend eight hours a day maintaining the script that does my job.

(108 characters, one line, no trailing newline.)

## Run

```sh
python3 main.py
```

Writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (default `/output`).
